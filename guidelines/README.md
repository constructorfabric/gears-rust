6. Follow [CONTRIBUTING.md](../CONTRIBUTING.md) for commits and pull requests.
7. Read [MATURITY.md](./MATURITY.md) for gear maturity levels, unstable features in stable gears, and how they change review and versioning rules.
8. Use [DESIGN_REVIEW.md](./DESIGN_REVIEW.md) for design reviews and severity.
