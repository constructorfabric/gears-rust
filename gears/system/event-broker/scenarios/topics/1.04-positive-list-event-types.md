# List event types

Returns a paged list of event types registered in `types_registry`. Producers use this to discover which event types are available on a given topic; consumers use it to understand the data schemas they'll receive.

## Request

```http
GET /v1/event-types?topic=gts.cf.core.events.topic.v1~acme.orders.v1&limit=20 HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`
- Each item is a DTO projected from that event type's registered type schema: `id` is the schema's own type identifier, `topic` and `allowed_subject_types` are its resolved trait values, and `data_schema` is the payload contract composed from the `data` narrowings along the derivation chain.

## Side effects

- Read-only. No state changes.
