# List storage segments for an empty partition

A registered `(topic, partition)` with no stored events answers with an empty segment manifest.

This holds for any registered partition with no stored events (feature 0003, AC-1): the envelope is `(0, 0)`, both times are `null` and `segments[]` is empty.

## Request

```http
GET /v1/topics/segments?topic=gts.cf.core.events.topic.v1~acme.orders.v1&partition=0 HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`

```json
{
  "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
  "partition": 0,
  "start_sequence": 0,
  "end_sequence": 0,
  "start_time": null,
  "end_time": null,
  "segments": []
}
```
