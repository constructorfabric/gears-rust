# 403 — authenticated but not authorized

A valid token whose principal lacks the required permission is rejected `403`. The SDK rolls up every `403`, whatever its fine-grained code (`TopicNotAuthorized`, `EventTypeNotAuthorized`, `SubjectTypeNotAuthorized`, `TenantIdNotAuthorized`, `SubscriptionNotOwned`, `ConsumerGroupNotOwned` and `ConsumerGroupNotAuthorized` among them), into one `Unauthorized`; on the wire every `403` carries the title `Permission Denied`, and `context.resource_type` names the refused resource kind (topic, event type, subscription, consumer group or producer: the subscription type for `SubscriptionNotOwned`, the consumer-group type for `ConsumerGroupNotOwned` and `ConsumerGroupNotAuthorized`), or the generic request type for the other codes.

## Request

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "consumer_group": "{group_id}",
  "client_agent": "worker/1.0.0",
  "interests": [ { "topic": "gts.cf.core.events.topic.v1~acme.restricted.v1", "subject_tenant": "<tenant-uuid>", "ownership_filter": "entire_tenant", "types": ["gts.cf.core.events.event.v1~acme.restricted.*"] } ]
}
```

## Expected response

- `403 Forbidden` (`PD`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "You do not have permission to perform this operation",
  "instance": "/v1/subscriptions",
  "trace_id": "<request-trace-id>",
  "context": {
    "reason": "<PDP deny reason, or \"access denied by policy\">",
    "resource_type": "gts.cf.core.events.topic.v1~"
  }
}
```

## Notes

- Sibling `403` conditions share this envelope, the ownership refusals (`SubscriptionNotOwned`, `ConsumerGroupNotOwned`) and the group check's `ConsumerGroupNotAuthorized` included: the generic `detail`, the refusal reason in `context.reason` and the resource kind in `context.resource_type`; no root-level field names the resource. Producer-side `Forbidden` on publish follows the same shape.
- See the endpoint-specific instance: [consumer/subscriptions/negative-1.6](../consumer/subscriptions/1.06-negative-join-unauthorized-topic.md).
