# Batch rejected for an event whose `meta` does not fit its producer's mode

Each event of a batch carries its own `meta`, checked against its producer's registered mode as a single publish's is ([flows/1.13](../flows/1.13-negative-chained-publish-missing-previous.md)). Every event is checked before any is enqueued, so one event of the wrong shape rejects the whole batch with that event's code: nothing is admitted.

## Setup

- Topic `acme.orders.v1` and event type `acme.orders.created.v1` registered.
- Producer `{producer_id}` registered in chained mode, with no event published yet.

## Request

The run is `[0->1, ?->2, 2->3]`: the second event omits `meta.previous`.

```http
POST /v1/events:batch HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "events": [
    {
      "id": "e0000000-0000-0000-0000-000000000141",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "subject_tenant": "<tenant-uuid>", "source": "svc", "subject": "o-1",
      "subject_type": "gts.acme.shop.orders.order.v1~",
      "occurred_at": "2026-05-29T10:10:00Z", "data": { "order_id": "o-1", "total_cents": 1 },
      "meta": { "version": 1, "producer": "{producer_id}", "previous": 0, "sequence": 1 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000000142",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "subject_tenant": "<tenant-uuid>", "source": "svc", "subject": "o-2",
      "subject_type": "gts.acme.shop.orders.order.v1~",
      "occurred_at": "2026-05-29T10:10:01Z", "data": { "order_id": "o-2", "total_cents": 2 },
      "meta": { "version": 1, "producer": "{producer_id}", "sequence": 2 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000000143",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "subject_tenant": "<tenant-uuid>", "source": "svc", "subject": "o-3",
      "subject_type": "gts.acme.shop.orders.order.v1~",
      "occurred_at": "2026-05-29T10:10:02Z", "data": { "order_id": "o-3", "total_cents": 3 },
      "meta": { "version": 1, "producer": "{producer_id}", "previous": 2, "sequence": 3 }
    }
  ]
}
```

## Expected response

- `400 Bad Request` (`PD`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "ChainModeFieldsMissing: a chained-mode publish needs meta.previous and meta.sequence",
  "instance": "/v1/events:batch",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "ChainModeFieldsMissing: a chained-mode publish needs meta.previous and meta.sequence",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- No event from the batch is admitted (all-or-nothing).
- `GET /v1/producers/{producer_id}/cursors` lists no topic: the chain was not started.

## Notes

The `detail` does not name the offending event's position.
