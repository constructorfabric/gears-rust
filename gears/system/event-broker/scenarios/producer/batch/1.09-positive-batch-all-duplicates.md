# Batch of only duplicates answered 200

A chained run whose last event's `sequence` equals the producer's committed `last_sequence` is a duplicate as a whole (feature 0001 §5.2, R4), and a batch of only duplicates is answered `200 OK`. This is how a producer that lost the ack of a `:batch` resends it safely.

## Setup

- Topic `acme.orders.v1` and event type `acme.orders.created.v1` registered.
- Producer `{producer_id}` registered in chained mode; `last_sequence` for `({producer_id}, "acme.orders.v1")` is `9`.
- The batch below was answered `202 Accepted`, which moved `last_sequence` to `12`, and its ack was lost.

## Request

The producer resends the same batch.

```http
POST /v1/events:batch HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "events": [
    {
      "id": "e0000000-0000-0000-0000-000000001310",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-resend",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1~",
      "occurred_at": "2026-05-29T10:11:00Z",
      "data": { "order_id": "order-resend", "total_cents": 100 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 9, "sequence": 10 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001311",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-resend",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1~",
      "occurred_at": "2026-05-29T10:11:01Z",
      "data": { "order_id": "order-resend", "total_cents": 200 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 10, "sequence": 11 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001312",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-resend",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1~",
      "occurred_at": "2026-05-29T10:11:02Z",
      "data": { "order_id": "order-resend", "total_cents": 300 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 11, "sequence": 12 }
    }
  ]
}
```

## Expected response

- `200 OK`, no body.

## Side effects

- The producer's `last_sequence` for the topic stays at `12`.
- Each event of the run is stored once; the resend stores nothing.
