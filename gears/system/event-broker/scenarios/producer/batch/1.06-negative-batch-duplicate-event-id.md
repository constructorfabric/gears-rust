# Batch rejected for repeating an event id

Every event of a `:batch` carries its own `id` (feature 0001 §5.2, R13). A batch that repeats an `id` is rejected `400 duplicate_event_id`, naming the repeat by its position.

## Setup

- Topic `acme.orders.v1` and event type `acme.orders.created.v1` registered.
- Producer `{producer_id}` registered in chained mode, with no event published yet.

## Request

The second event repeats the first event's `id`.

```http
POST /v1/events:batch HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "events": [
    {
      "id": "e0000000-0000-0000-0000-000000001101",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-repeat",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1",
      "occurred_at": "2026-05-29T10:11:00Z",
      "data": { "order_id": "order-repeat", "total_cents": 100 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 0, "sequence": 1 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001101",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-repeat",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1",
      "occurred_at": "2026-05-29T10:11:01Z",
      "data": { "order_id": "order-repeat", "total_cents": 200 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 1, "sequence": 2 }
    }
  ]
}
```

## Expected response

- `400 Bad Request` (`PD`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "Request validation failed",
  "instance": "/v1/events:batch",
  "trace_id": "<request-trace-id>",
  "context": {
    "field_violations": [
      {
        "field": "events[1].id",
        "description": "repeats the id of an earlier event of the batch",
        "reason": "duplicate_event_id"
      }
    ],
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is stored. `GET /v1/producers/{producer_id}/cursors` still lists no topic for the producer.
