# Batch rejected for one event in an unreachable tenant

A batch is all-or-nothing. Each event's tenant is authorized on its own, in batch order, before any event is enqueued. One event in a tenant the caller cannot reach (outside its subtree, no barrier right) rejects the whole batch `403 TenantIdNotAuthorized`; the events before and after it are not enqueued either.

## Setup

- Tenant tree: `T123` (the caller's tenant) has the child `T234`; `T999` is not below `T123`.
- The caller, in `T123`, holds `produce` on `gts.cf.core.events.event.v1~acme.orders.created.v1~`.

## Request

```http
POST /v1/events:batch HTTP/1.1
Host: broker.example.com
Authorization: Bearer <T123-token>
Content-Type: application/json

{
  "events": [
    {
      "id": "e0000000-0000-0000-0000-000000001301",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "subject_tenant": "<T234-uuid>",
      "source": "order-service",
      "subject": "order-1",
      "subject_type": "gts.acme.shop.orders.order.v1~",
      "occurred_at": "2026-06-15T10:00:00Z",
      "data": { "order_id": "order-1" }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001302",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "subject_tenant": "<T999-uuid>",
      "source": "order-service",
      "subject": "order-2",
      "subject_type": "gts.acme.shop.orders.order.v1~",
      "occurred_at": "2026-06-15T10:00:01Z",
      "data": { "order_id": "order-2" }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001303",
```

## Expected response

- `403 Permission Denied` (`TenantIdNotAuthorized`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "You do not have permission to perform this operation",
  "instance": "/v1/events:batch",
  "trace_id": "<request-trace-id>",
  "context": {
    "reason": "access denied by policy",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- No event of the batch is stored or enqueued, including the two in `T234`.
- The third event is never authorized: the batch stops at the refused event.
