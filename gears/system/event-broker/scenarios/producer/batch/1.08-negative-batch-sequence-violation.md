# Batch rejected for a run behind the committed head

A chained run advances only when its first event's `previous` equals the producer's committed `last_sequence` (feature 0001 §5.2, R4). A run that links on its own but sits behind the head rejects the whole batch `412`, naming the run's first event, its producer, its topic and the committed head.

## Setup

- Topic `acme.orders.v1` and event type `acme.orders.created.v1` registered.
- Producer `{producer_id}` registered in chained mode; `last_sequence` for `({producer_id}, "acme.orders.v1")` is `7`.

## Request

The run `[3->4, 4->5]` links on its own, but the head is `7`.

```http
POST /v1/events:batch HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "events": [
    {
      "id": "e0000000-0000-0000-0000-000000001611",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-stale",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1",
      "occurred_at": "2026-05-29T10:11:01Z",
      "data": { "order_id": "order-stale", "total_cents": 400 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 3, "sequence": 4 }
    },
    {
      "id": "e0000000-0000-0000-0000-000000001612",
      "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
      "tenant_id": "<tenant-uuid>",
      "source": "order-service",
      "subject": "order-stale",
      "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1",
      "occurred_at": "2026-05-29T10:11:02Z",
      "data": { "order_id": "order-stale", "total_cents": 500 },
      "meta": { "version": 1, "producer_id": "{producer_id}", "previous": 4, "sequence": 5 }
    }
  ]
}
```

## Expected response

- `412 Precondition Failed` (`PD`)
- `context.violations[0].description` carries `index`, `producer_id`, `topic` and `last_sequence`, the committed head, last.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.failed_precondition.v1~",
  "title": "Failed Precondition",
  "status": 412,
  "detail": "Operation precondition not met",
  "instance": "/v1/events:batch",
  "trace_id": "<request-trace-id>",
  "context": {
    "resource_type": "gts.cf.core.events.topic.v1~",
    "resource_name": "gts.cf.core.events.topic.v1~acme.orders.v1",
    "violations": [
      {
        "type": "sequence_mismatch",
        "subject": "(producer)",
        "description": "index=0 producer_id={producer_id} topic=gts.cf.core.events.topic.v1~acme.orders.v1 last_sequence=7"
      }
    ]
  }
}
```

## Side effects

- Nothing is stored; the producer's `last_sequence` for the topic stays at `7`.
