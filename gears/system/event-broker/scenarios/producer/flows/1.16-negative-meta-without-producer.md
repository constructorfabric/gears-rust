# `meta` with a sequence but no producer is rejected

`meta.previous` and `meta.sequence` belong to a registered producer's chain. A `meta` that carries either of them but no `meta.producer` is rejected `400 MetaWithoutProducerId`, before any producer lookup: nothing is admitted.

A stateless publish omits `meta` entirely, or sends one with neither field at a supported version ([1.18](./1.18-positive-meta-with-only-version-is-stateless.md)). A deduplicating publish names its producer. Either fix is open to the sender; the broker does not guess which was meant.

## Setup

- Topic `acme.orders.v1` and event type `acme.orders.created.v1` registered. No producer is involved.

## Request

`meta.sequence` is present; `meta.producer` is not. A literal nil UUID in `meta.producer` counts as absent and is rejected the same way, and so is a `meta` carrying `meta.previous` without a producer.

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "d0000000-0000-0000-0000-000000000016",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "subject_tenant": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-anon",
  "subject_type": "gts.acme.shop.orders.order.v1~",
  "occurred_at": "2026-05-29T10:07:00Z",
  "data": { "order_id": "order-anon", "total_cents": 700 },
  "meta": { "version": 1, "sequence": 5 }
}
```

## Expected response

- `400 Bad Request` (`PD`)
- The `detail` names the code and the rule. It carries no part of the submitted value.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "MetaWithoutProducerId: meta carries previous or sequence but no producer",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "MetaWithoutProducerId: meta carries previous or sequence but no producer",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is admitted: a stream read of the tenant delivers no event for this request.
