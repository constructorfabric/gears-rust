# Chained-mode publish without `meta.sequence` is rejected

A chained-mode `meta` carries both `meta.previous` and `meta.sequence`. A publish that omits `meta.sequence` is rejected `400 ChainModeFieldsMissing` as a mode-shape violation, before any sequence comparison: nothing is admitted and the chain does not move.

The missing sequence is not read as `0`: the event would otherwise claim a position in the chain its producer never assigned.

## Setup

- Producer `{producer_id}` is registered in chained mode, with no event published yet.

## Request

`meta.previous` is present; `meta.sequence` is not.

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "d0000000-0000-0000-0000-000000000014",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "subject_tenant": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-chain",
  "subject_type": "gts.acme.shop.orders.order.v1~",
  "occurred_at": "2026-05-29T10:07:00Z",
  "data": { "order_id": "order-chain", "total_cents": 700 },
  "meta": { "version": 1, "producer": "{producer_id}", "previous": 0 }
}
```

## Expected response

- `400 Bad Request` (`PD`)
- The `detail` names the code and the rule. It carries no part of the submitted value.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "ChainModeFieldsMissing: a chained-mode publish needs meta.previous and meta.sequence",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "ChainModeFieldsMissing: a chained-mode publish needs meta.previous and meta.sequence",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is admitted.
- `GET /v1/producers/{producer_id}/cursors` lists no topic: the chain was not started.

## Notes

A chained publish that omits `meta.previous` is rejected with the same code ([1.13](./1.13-negative-chained-publish-missing-previous.md)).
