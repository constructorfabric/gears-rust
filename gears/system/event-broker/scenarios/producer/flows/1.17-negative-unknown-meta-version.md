# `meta.version` newer than the broker supports is rejected

`meta.version` lets the producer protocol evolve apart from the event schema. The broker reads `meta` blocks up to version `1`; a newer one is rejected `400 UnknownMetaVersion` rather than read as if it were version `1`, since a newer block may carry fields whose meaning the broker does not know.

For a block that names a producer, the check runs after the producer lookup and the mode-shape check. For a block that names none, it runs after the `MetaWithoutProducerId` check: a block with no producer and no chain field is a stateless publish's ([1.18](./1.18-positive-meta-with-only-version-is-stateless.md)) only at a supported version (ADR-0004, "Mode-Shape Enforcement at Publish Time").

## Setup

- Producer `{producer_id}` is registered in chained mode, with no event published yet.

## Request - a block naming a producer

The block has the chained shape, at `version` `2`.

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "d0000000-0000-0000-0000-000000000017",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "subject_tenant": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-chain",
  "subject_type": "gts.acme.shop.orders.order.v1~",
  "occurred_at": "2026-05-29T10:07:00Z",
  "data": { "order_id": "order-chain", "total_cents": 700 },
  "meta": { "version": 2, "producer": "{producer_id}", "previous": 0, "sequence": 1 }
}
```

## Expected response

- `400 Bad Request` (`PD`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "UnknownMetaVersion: meta.version is newer than the broker supports (1)",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "UnknownMetaVersion: meta.version is newer than the broker supports (1)",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is admitted.
- `GET /v1/producers/{producer_id}/cursors` lists no topic: the chain was not started.

## Request - a block naming no producer

The block carries only `version` `2`: no producer and no chain field.

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "d0000000-0000-0000-0000-000000000117",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "subject_tenant": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-anon",
  "subject_type": "gts.acme.shop.orders.order.v1~",
  "occurred_at": "2026-05-29T10:08:00Z",
  "data": { "order_id": "order-anon", "total_cents": 700 },
  "meta": { "version": 2 }
}
```

## Expected response

- `400 Bad Request` (`PD`), the same body as for the block naming a producer.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "UnknownMetaVersion: meta.version is newer than the broker supports (1)",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "UnknownMetaVersion: meta.version is newer than the broker supports (1)",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is admitted: a stream read of the tenant delivers no event for this request.
