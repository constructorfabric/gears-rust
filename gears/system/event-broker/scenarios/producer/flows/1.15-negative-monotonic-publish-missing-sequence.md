# Monotonic-mode publish without `meta.sequence` is rejected

A producer registered in monotonic mode orders its events by `meta.sequence` alone. A publish that omits it is rejected `400 MonotonicModeFieldsViolation` as a mode-shape violation, before any sequence comparison: nothing is admitted and `last_sequence` does not move.

The missing sequence is not read as `0`: the event would otherwise claim a position its producer never assigned.

## Setup

- Producer `{producer_id}` is registered in monotonic mode, with no event published yet.

## Request

`meta` names the producer and carries neither `meta.previous` nor `meta.sequence`.

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "d0000000-0000-0000-0000-000000000015",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "subject_tenant": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-mono",
  "subject_type": "gts.acme.shop.orders.order.v1~",
  "occurred_at": "2026-05-29T10:07:00Z",
  "data": { "order_id": "order-mono", "total_cents": 700 },
  "meta": { "version": 1, "producer": "{producer_id}" }
}
```

## Expected response

- `400 Bad Request` (`PD`)
- The `detail` names the code and the rule. It carries no part of the submitted value.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "MonotonicModeFieldsViolation: a monotonic-mode publish needs meta.sequence and must omit meta.previous",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "format": "MonotonicModeFieldsViolation: a monotonic-mode publish needs meta.sequence and must omit meta.previous",
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- Nothing is admitted.
- `GET /v1/producers/{producer_id}/cursors` lists no topic.

## Notes

A monotonic publish that carries `meta.previous` is rejected with the same code ([1.12](./1.12-negative-monotonic-publish-carries-previous.md)).
