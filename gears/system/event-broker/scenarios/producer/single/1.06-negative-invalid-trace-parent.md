# Publish rejects a malformed trace_parent

`trace_parent` is optional. When a publish carries it, it must be a W3C traceparent: four lowercase hex groups of 2, 32, 16 and 2 digits joined by `-` (the base event schema's pattern). A malformed value is rejected with `400`, and the event is not admitted. The rejection names the field and the rule, never the value.

## Setup

- Event type `gts.cf.core.events.event.v1~acme.orders.created.v1~` is registered.

## Request

```http
POST /v1/events HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "id": "e0000000-0000-0000-0000-000000000006",
  "type": "gts.cf.core.events.event.v1~acme.orders.created.v1~",
  "tenant_id": "<tenant-uuid>",
  "source": "order-service",
  "subject": "order-42",
  "subject_type": "gts.cf.core.events.subject.v1~acme.order.v1~",
  "occurred_at": "2026-05-29T10:10:00Z",
  "trace_parent": "00-0AF7651916CD43DD8448EB211C80319C-B7AD6B7169203331-01",
  "data": { "order_id": "order-42", "total_cents": 4299 }
}
```

## Expected response

- `400 Bad Request` (`PD`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "Request validation failed",
  "instance": "/v1/events",
  "trace_id": "<request-trace-id>",
  "context": {
    "field_violations": [
      {
        "field": "trace_parent",
        "description": "must be a W3C traceparent: four lowercase hex groups of 2, 32, 16 and 2 digits joined by '-'",
        "reason": "invalid_event_field"
      }
    ],
    "resource_type": "gts.cf.core.events.request.v1~"
  }
}
```

## Side effects

- No event is admitted.
- A batch (`POST /v1/events:batch`) carrying one such event is rejected whole with the same violation.
