# List active subscriptions

Returns a paged list of subscriptions visible to the caller - the subscriptions whose tenant the caller may consume as. Useful for observability and debugging (e.g., "how many consumers are active for this group?").

## Request

```http
GET /v1/subscriptions?limit=10 HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`
- Each interest is echoed without `unmatched_types`: that field belongs to the JOIN response only and is not recomputed here.

```json
{
  "items": [
    {
      "id": "11111111-2222-3333-4444-555555555555",
      "consumer_group": "gts.cf.core.events.consumer_group.v1~{uuid}",
      "client_agent": "order-worker/1.4.0 cf-event-broker-sdk/0.1.0",
      "interests": [
        { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "subject_tenant": "<tenant-uuid>", "ownership_filter": "entire_tenant", "barrier_mode": "respect", "types": ["gts.cf.core.events.event.v1~acme.orders.*"], "filter": null }
      ],
      "assigned": [
        { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 0 },
        { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 1 }
      ],

    }
  ],

    "prev_cursor": null,

  }
}
```

## Side effects

- Read-only. No state changes.
- A subscription of a tenant the caller may not consume as is left out.
- The list holds the subscriptions whose tenant the caller may consume as: under a tree-aware policy, its own tenant and the tenants of its subtree, not past a self-managed tenant's barrier.
- A caller whose subject or tenant is the nil UUID gets `403 Permission Denied` (`TenantIdNotAuthorized`), not an empty page (see [auth/1.11](../../auth/1.11-negative-nil-caller-management.md)).
