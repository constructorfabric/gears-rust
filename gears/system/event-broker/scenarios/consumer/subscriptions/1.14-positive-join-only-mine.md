# JOIN without an ownership filter reads the caller's own events

An interest's `ownership_filter` decides which events of its tenant it is delivered. The default, `only_mine`, delivers only events whose `subject_owner` is the caller, in the caller's own tenant: the caller's mailbox. An event with no `subject_owner` is never delivered to `only_mine`; reading it needs `entire_tenant`. An interest that names neither `ownership_filter` nor `subject_tenant` therefore reads the caller's own events in the caller's tenant, and the JOIN echoes both resolved values.

## Setup

- Run [Create an anonymous group](../groups/1.01-positive-create-anonymous-group.md). Group id available as `{group_id}`.
- Topic `gts.cf.core.events.topic.v1~acme.orders.v1` is registered with 1 partition, with event type `gts.cf.core.events.event.v1~acme.orders.order_placed.v1~`.
- The caller's token names tenant `<caller-tenant-uuid>`.

## Request

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "consumer_group": "{group_id}",
  "client_agent": "order-inbox/1.0.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "types": ["gts.cf.core.events.event.v1~acme.orders.order_placed.v1~"]
    }
  ]
}
```

## Expected response

- `201 Created`
- The interest is echoed with `"ownership_filter": "only_mine"` and `"subject_tenant"` set to the caller's tenant.

```json
{
  "id": "{sub_id}",
  "consumer_group": "{group_id}",
  "client_agent": "order-inbox/1.0.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<caller-tenant-uuid>",
      "ownership_filter": "only_mine",
      "barrier_mode": "respect",
      "types": ["gts.cf.core.events.event.v1~acme.orders.order_placed.v1~"],
      "filter": null,
      "unmatched_types": []
    }
  ],
  "assigned": [
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 0 }
  ],
  "topology_version": 1,
  "created_at": "2026-05-29T10:00:00Z"
}
```

## Side effects

- The subscription `{sub_id}` is created; its stream delivers only events whose `subject_owner` is the caller ([Only-mine delivery](../stream/1.17-positive-only-mine-delivery.md)).
- An explicit `"subject_tenant": "<caller-tenant-uuid>"` is accepted and gives the same echo. Any other tenant is refused ([JOIN only_mine for another tenant](1.19-negative-join-only-mine-foreign-tenant.md)).
