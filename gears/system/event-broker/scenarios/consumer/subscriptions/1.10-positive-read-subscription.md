# Read a single subscription

Returns the record for one subscription by id - its interests, current assignment, topology version and creation time; its `session_timeout` and expiry are not returned. Used by SDK recovery logic and observability tooling.

## Setup

- Run [Cold JOIN against a fresh group](./1.01-positive-cold-join-fresh-group.md). Subscription id `{sub_id}` available.

## Request

```http
GET /v1/subscriptions/{sub_id} HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`
- Each interest is echoed without `unmatched_types`: that field belongs to the JOIN response only and is not recomputed here.

```json
{
  "id": "{sub_id}",
  "consumer_group": "gts.cf.core.events.consumer_group.v1~{uuid}",
  "client_agent": "order-worker/1.4.0 cf-event-broker-sdk/0.1.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<tenant-uuid>",
      "ownership_filter": "entire_tenant",
      "barrier_mode": "respect",
      "types": ["gts.cf.core.events.event.v1~acme.orders.*"],
      "filter": null
    }
  ],
  "assigned": [
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 0 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 1 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 2 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 3 }
  ],
  "topology_version": 1,
  "created_at": "2026-05-29T10:00:00Z"
}
```

## Side effects

- Read-only. A GET does not change the subscription's lifecycle state.

## Errors

- `404 Not Found` — subscription expired or was deleted.
