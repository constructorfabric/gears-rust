# JOIN naming an event type the topic has not registered

A consumer can JOIN before the producer of a type has registered it. The JOIN succeeds, and the response reports each interest entry that matched no event type registered on the topic in that interest's `unmatched_types`, so a typo in a type or a pattern is visible at once. Events of such a type are delivered once it registers and the caller may consume it.

## Setup

- Run [Create an anonymous group](../groups/1.01-positive-create-anonymous-group.md). Group id available as `{group_id}`.
- Topic `gts.cf.core.events.topic.v1~acme.orders.v1` is registered with 1 partition, with event type `gts.cf.core.events.event.v1~acme.orders.order_placed.v1~`.
- Event type `gts.cf.core.events.event.v1~acme.orders.order_refunded.v1~` is not registered.

## Request

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "consumer_group": "{group_id}",
  "client_agent": "refund-worker/1.0.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<tenant-uuid>",
      "ownership_filter": "entire_tenant",
      "types": ["gts.cf.core.events.event.v1~acme.orders.order_refunded.v1~"]
    }
  ]
}
```

## Expected response

- `201 Created`
- The interest's `unmatched_types` names the unregistered type. It is `[]` for an interest whose entries all matched.
- On a topic with more than 256 registered event types only exact entries are checked; a wildcard is never reported there.

```json
{
  "id": "{sub_id}",
  "consumer_group": "{group_id}",
  "client_agent": "refund-worker/1.0.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<tenant-uuid>",
      "ownership_filter": "entire_tenant",
      "barrier_mode": "respect",
      "types": ["gts.cf.core.events.event.v1~acme.orders.order_refunded.v1~"],
      "filter": null,
      "unmatched_types": ["gts.cf.core.events.event.v1~acme.orders.order_refunded.v1~"]
    }
  ],
  "assigned": [
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 0 }
  ],
  "topology_version": 1,
  "created_at": "2026-05-29T10:00:00Z"
}
```

## Side effects

- The subscription `{sub_id}` is created, as for any other JOIN.
- `unmatched_types` is not stored: [Read subscription](1.10-positive-read-subscription.md) and [List subscriptions](1.09-positive-list-subscriptions.md) echo the interest without it.
