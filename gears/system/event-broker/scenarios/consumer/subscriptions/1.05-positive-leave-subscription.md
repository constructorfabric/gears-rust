# LEAVE a subscription

A consumer terminates its subscription. The broker releases the subscription's partitions back to the group and rebalances any remaining members.

## Setup

- Run [Cold JOIN against a fresh group](./1.01-positive-cold-join-fresh-group.md) → `{sub_id}` on group `{group_id}`.

## Request

```http
DELETE /v1/subscriptions/{sub_id} HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `204 No Content`

## Side effects

- `evbk_subscription({sub_id})` is absent (not yet implemented, tracked in #5979).
- The partitions it held are released; if other members exist, the group's topology_version advances and survivors receive a `topology` frame.
- `subsequent GET /v1/events:stream?subscription={sub_id}` returns `404 SubscriptionNotFound`.
- LEAVE discards this subscription session and neither writes nor deletes a cursor: a cursor a SEEK stored for the group survives, and a future member resumes from it unless it SEEKs from consumer-owned progress. This Setup runs no SEEK, so a future member's stream open answers `409 PositionsNotSet` until it SEEKs.
