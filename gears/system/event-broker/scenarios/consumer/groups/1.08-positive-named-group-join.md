# JOIN a named consumer group (no creation step)

Named consumer groups are not yet implemented (tracked in #5702): today this JOIN answers `501 Unimplemented` before the group is read. The named-group setup, the response, side effects and errors below describe the planned behaviour.

Named groups are pre-registered via `types_registry` at module startup (not yet implemented, tracked in #5702). Any principal with a `consume` grant on the GTS identifier can JOIN directly (not yet implemented, tracked in #5702) - there is no `POST /v1/consumer-groups` step. This is the pattern for shared platform-level consumers and cross-module consumption.

## Setup

- Group `gts.cf.core.events.consumer_group.v1~vendor.order-processors.v1` is registered in `types_registry` by the `order-processor` module at startup. The row exists in `event_broker_consumer_group` with `kind = named`.
- Caller holds `gts.cf.core.events.consumer_group.v1~vendor.order-processors.v1:consume` permission.
- Topic `gts.cf.core.events.topic.v1~acme.orders.v1` is registered with 4 partitions.

## Request

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Content-Type: application/json

{
  "consumer_group": "gts.cf.core.events.consumer_group.v1~vendor.order-processors.v1",
  "client_agent": "order-processor/2.0.0 cf-event-broker-sdk/0.1.0",
  "session_timeout": "PT60S",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<tenant-uuid>",
      "ownership_filter": "entire_tenant",
      "types": ["gts.cf.core.events.event.v1~acme.orders.*"]
    }
  ]
}
```

## Expected response

- `201 Created`

```json
{
  "id": "aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee",
  "consumer_group": "gts.cf.core.events.consumer_group.v1~vendor.order-processors.v1",
  "assigned": [
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 0 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 1 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 2 },
    { "topic": "gts.cf.core.events.topic.v1~acme.orders.v1", "partition": 3 }
  ],
  "topology_version": 1
}
```

## Side effects

- `evbk_subscription(aaaaaaaa-...)` created in cache (not yet implemented, tracked in #5979).
- GroupState for `vendor.order-processors.v1` created in cache with `topology_version = 1`.
- A second instance JOINing with the same group identifier triggers a rebalance (see [positive-1.11](../subscriptions/1.11-positive-second-join-triggers-rebalance.md)).

## Errors

- `403 Permission Denied` — caller lacks `:consume` on this named group identifier.
- `404 Not Found` - group identifier not in `event_broker_consumer_group` (was never registered via `types_registry`).
