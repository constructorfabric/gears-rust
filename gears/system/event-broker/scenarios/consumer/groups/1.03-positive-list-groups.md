# List consumer groups visible to the caller

Read-only listing of the groups the caller may see: anonymous groups whose tenant the caller may consume as (under a tree-aware policy, its own tenant and the tenants of its subtree, not past a self-managed tenant's barrier), and named groups whose group check allows `consume`.

## Request

```http
GET /v1/consumer-groups HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`
- Body is an array of the group records the caller may see (see above).

```json
[
  {
    "id": "gts.cf.core.events.consumer_group.v1~7b2c1e9a-4f3d-4a2b-9c8e-1d2f3a4b5c6d",
    "tenant": "<tenant-uuid>",
    "owner_principal": "<principal>",
    "kind": "anonymous",
    "description": "order-fulfilment workers",
    "created_at": "2026-05-29T10:00:00Z"
  }
]
```

## Side effects

- Read-only. No state changes.
- A caller whose subject or tenant is the nil UUID gets `403`, not an empty page.
- That refusal's code is `TenantIdNotAuthorized` (see auth/1.11).
