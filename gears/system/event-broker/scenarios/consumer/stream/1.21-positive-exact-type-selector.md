# Exact type selector delivers only its type

An interest's `types` entries are matched against each event's `type` with GTS pattern semantics: a bare type id covers its derived types, a trailing `*` covers its prefix. A type id with no derived types registered therefore selects exactly that type. Another type on the same topic, even one derived from the same base, is not delivered.

## Setup

- Topic `gts.cf.core.events.topic.v1~acme.orders.x.orders.v1` (1 partition) has two event types, neither derived from the other: `gts.cf.core.events.event.v1~acme.orders.x.created.v1~` and `gts.cf.core.events.event.v1~acme.orders.x.shipped.v1~`.
- [Cold JOIN](../subscriptions/1.01-positive-cold-join-fresh-group.md) with one interest, then [SEEK earliest](../positions/1.01-positive-seek-earliest.md) → seeded `{sub_id}`:

```json
{
  "topic": "gts.cf.core.events.topic.v1~acme.orders.x.orders.v1",
  "subject_tenant": "<tenant-uuid>",
  "ownership_filter": "entire_tenant",
  "types": ["gts.cf.core.events.event.v1~acme.orders.x.created.v1~"]
}
```

## Request

```http
GET /v1/events:stream?subscription={sub_id} HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Accept: multipart/mixed
```

Once the stream is open, two events are published for `<tenant-uuid>`, in this order: event A of type `...x.shipped.v1~`, then event B of type `...x.created.v1~`.

## Expected response

- `200 OK`, `Content-Type: multipart/mixed; boundary=<...>`.
- The `topology` frame assigns the interest's topic and partition.
- The first `event` frame is event B. Event A is never delivered.

```
--<boundary>
Content-Type: application/json

{ "kind": "event", "payload": { "id": "<event-b-id>", "type": "gts.cf.core.events.event.v1~acme.orders.x.created.v1~", "subject_tenant": "<tenant-uuid>", "partition": 0, "sequence": <sequence>, ... } }
```

## Side effects

- `subscription {sub_id} next frame is event <event-b-id>`: the topic has one partition and A was stored first, so a stream that delivered A would deliver it first.
- Event A stays stored; a subscription selecting its type receives it.
