# Wildcard event-type interest streams every type

A subscription interest may name the all-event-types wildcard - the event base type with a trailing `*` (`gts.cf.core.events.event.v1~*`) - instead of an explicit list. It matches every derived event type on the topic, so an event published as a concrete type is still delivered. This is the interest a topic-only subscription carries (an SDK consumer built with topics but no explicit event-type patterns emits exactly this pattern), and it resolves through the same GTS pattern matching as an explicit type.

## Setup

- [Cold JOIN](../subscriptions/1.01-positive-cold-join-fresh-group.md) with one interest whose `types` is `["gts.cf.core.events.event.v1~*"]` (the all-types wildcard) rather than a concrete type, then [SEEK earliest](../positions/1.01-positive-seek-earliest.md) → seeded `{sub_id}`.

## Request

```http
GET /v1/events:sse?subscription_id={sub_id} HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
Accept: text/event-stream
```

An event of a concrete type under the wildcard's base (`gts.cf.core.events.event.v1~<...>~`) is published to the topic on the other side.

## Expected response

- `200 OK`, `Content-Type: text/event-stream`.
- The `topology` frame assigns the interest's topic/partition.
- The published concrete-type event is delivered as one `event` frame - the wildcard interest matches it.

```
event: topology
data: {"kind":"topology","topology_version":1,"assigned":[{"topic":"<topic>","partition":0,"offset":0,"last_examined":0}]}

event: event
data: {"kind":"event","payload":{"type":"gts.cf.core.events.event.v1~<...>~","topic":"<topic>","partition":0,"sequence":<n>, ...}}
```

## Side effects

- Identical delivery semantics to an explicit-type interest ([SSE event stream](1.09-positive-sse-event-stream.md)); the wildcard changes only which types are admitted, not how events are framed or ordered.
- The base type used as a pattern (no `*`) would match itself plus its derived subtree and minor versions; the trailing `*` here is the explicit "every type on this topic" form.
