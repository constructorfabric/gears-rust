# Tenant B cannot JOIN tenant A's anonymous consumer group → 403 ConsumerGroupNotOwned

An anonymous consumer group belongs to the principal that created it, in its tenant: the broker records that principal's subject as the group's `owner_principal` and its tenant as the group's `tenant`. A JOIN by any other principal, the creator's subject in another tenant included, is rejected with `403 Permission Denied` (`ConsumerGroupNotOwned`): the broker checks the group's stored `owner_principal_id` and `tenant_id` (`caller.subject_id == group.owner_principal_id` and `caller.subject_tenant_id == group.tenant_id`) right after the group lookup, before any policy call, so a principal of another tenant gets this code whatever the policy would answer for its tenant.

## Setup

- Principal A of tenant A created group `gts.cf.core.events.consumer_group.v1~{uuid}` via `POST /v1/consumer-groups`. The group's `owner_principal` is principal A and its `tenant` is tenant A.
- Tenant B somehow obtained the group's GTS identifier (e.g., it appeared in a log, was guessed, etc.).

## Request (tenant B)

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-b-token>
Content-Type: application/json

{
  "consumer_group": "gts.cf.core.events.consumer_group.v1~{uuid}",
  "client_agent": "adversary/1.0.0",
  "session_timeout": "PT30S",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "subject_tenant": "<tenant-b-uuid>",
      "ownership_filter": "entire_tenant",
      "types": ["gts.cf.core.events.event.v1~acme.orders.*"]
    }
  ]
}
```

## Expected response

- `403 Permission Denied` (`ConsumerGroupNotOwned`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "You do not have permission to perform this operation",
  "instance": "/v1/subscriptions",
  "trace_id": "<request-trace-id>",
  "context": {
    "reason": "consumer group 'gts.cf.core.events.consumer_group.v1~{uuid}' was created by another principal",
    "resource_type": "gts.cf.core.events.consumer_group.v1~"
  }
}
```

## Side effects

- No subscription is created. No group state is modified.
- Tenant A's group and any active subscriptions within it are unaffected.
- The error does not reveal tenant A's identity or any details of the group's contents.
