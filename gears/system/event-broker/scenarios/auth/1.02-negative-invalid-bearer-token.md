# Expired or malformed token returns 401

A request with an `Authorization: Bearer` header whose token is expired, malformed, or signed with an unknown key is rejected by `toolkit-security` before any event-broker logic runs.

## Request

```http
GET /event-broker/v1/topics HTTP/1.1
Host: broker.example.com
Authorization: Bearer this-is-not-a-valid-jwt
traceparent: 00-0123456789abcdef0123456789abcdef-0123456789abcdef-01
```

## Expected response

- `401 Unauthenticated` with `Content-Type: application/problem+json`

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.unauthenticated.v1~",
  "title": "Unauthenticated",
  "status": 401,
  "detail": "Authentication required",
  "instance": "/event-broker/v1/topics",
  "trace_id": "0123456789abcdef0123456789abcdef",
  "context": {"reason": "AUTHN_FAILED"}
}
```

## Side effects

- No resource is accessed.
- The response uses the same `AUTHN_FAILED` reason for expired and malformed tokens.
