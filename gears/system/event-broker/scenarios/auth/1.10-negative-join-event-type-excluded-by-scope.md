# JOIN for an exact event type the consume scope excludes → 403

The broker asks the policy for `consume` on the topic once per group, naming the group's type patterns and the topic's registered types they match. The policy answers with a scope, which may list the event types the caller may read. After the answer, each exact type pattern with at least one registered type is checked against the scope: if the scope admits none of its types, the interest can never receive an event, so the JOIN is refused `403 EventTypeNotAuthorized`, naming the pattern. Wildcard patterns, and exact patterns with no registered type on the topic, are not checked.

## Setup

- Tenant tree: `T123` (the caller's tenant) has the child `T234`.
- Topic `gts.cf.core.events.topic.v1~acme.orders.topic.v1` has the registered event types `gts.cf.core.events.event.v1~acme.orders.created.v1~` and `gts.cf.core.events.event.v1~acme.orders.shipped.v1~`.
- The caller, in `T123`, holds `consume` on the topic in `T234` for `gts.cf.core.events.event.v1~acme.orders.shipped.v1~` only.
- Group `{group_id}` exists, created by the caller.

## Request

```http
POST /v1/subscriptions HTTP/1.1
Host: broker.example.com
Authorization: Bearer <T123-token>
Content-Type: application/json

{
  "consumer_group": "{group_id}",
  "client_agent": "worker/1.0.0",
  "interests": [
    {
      "topic": "gts.cf.core.events.topic.v1~acme.orders.topic.v1",
      "subject_tenant": "<T234-uuid>",
      "ownership_filter": "entire_tenant",
      "types": ["gts.cf.core.events.event.v1~acme.orders.created.v1~"]
    }
  ]
}
```

## Expected response

- `403 Permission Denied` (`EventTypeNotAuthorized`)

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "You do not have permission to perform this operation",
  "instance": "/v1/subscriptions",
  "trace_id": "<request-trace-id>",
  "context": {
    "reason": "calling principal lacks consume on event type 'gts.cf.core.events.event.v1~acme.orders.created.v1~'",
    "resource_type": "gts.cf.core.events.event_type.v1~"
  }
}
```

## Side effects

- No subscription is created; `GET /v1/subscriptions` for `{group_id}` lists none.
