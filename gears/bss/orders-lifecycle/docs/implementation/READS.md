Status: **implemented, independently gap-fix reviewed and locally verified** ([implementation report](../../../../../artifacts/orders-lifecycle-s2-20261006/S6-01-draft-S6-04-implementation.md), [gap review](../../../../../artifacts/orders-lifecycle-s2-20261006/S6-01-draft-S6-04-gap-review.md)). Scope: the **draft subset** of [S6-01](06-reads-and-production-readiness.md#s6-01--implement-coherent-currenthistorical-read-projections) (order detail, order list, per-order line page) and the whole of [S6-04](06-reads-and-production-readiness.md#s6-04--implement-read-access-logging-and-disclosure-failure-semantics) for those surfaces, required by S2-09's "minimal safe draft inspection" and the S2-12 milestone. Boundary order: `X-Delegation-Proof-Ref` → `page_size` → filters/unknown names → `cursor`, each a problem+json refusal with no access-log row. Strong `ETag` on the two per-order reads. Columns per §3.7: both targets NULL on a list, `order_id` NULL with `requested_order_ref` set on a missing target, D-115 actor class, catalog operation, supplied proof recorded as supplied, `internal_refusal_detail` only for a targeted proof denial; `accessed_at` stamped by the writer from the database clock inside the log transaction (OL-2), never an application clock. Retention is the S2-11 90-day purge (`RetentionTable::ReadAccessLog`); nothing new |
| Signals | `OtelReadSignals` on the process meter: `orders_read_access_log_write_failures_total{outcome}`, `orders_read_refusals_total{reason}`, `orders_read_delegation_proof_denials_total{kind}` (counted even where the public answer is `order-not-found`, D-141) |
